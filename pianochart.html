Audio to score

pianochart

给一个音频或视频链接，得到一份能弹的钢琴谱：五线谱分页图、简谱、MusicXML 和 MIDI。人声被分离掉，只留伴奏，非旋律声部收进左手。

仓库 npm

三档难度共用一份编配，只换调号

产物

五线谱

分页渲染 PNG 与 SVG

简谱

级数记法，括号区分左右手

MusicXML

导入 MuseScore 继续编辑

MIDI

试听与二次编曲，同源音高

比对图

怎么跑

在 DSH 里

装上 pianochart-dsh，对话里让它出谱

本地出谱服务

python -m pianochart.serve，粘链接出谱

命令行

pianochart.cli --input 链接 --preset all

边界

本站不代跑

本站是静态页，转写在你本机跑

只做伴奏

人声被丢弃，纯人声段落出不了谱

相似度不是准确率

相似度只比和声，不是逐音正确率
