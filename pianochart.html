Audio to score

pianochart

给一个音频或视频链接，得到一份能弹的钢琴谱：五线谱分页图、简谱、MusicXML 和 MIDI。人声被分离掉，只留伴奏，非旋律声部收进左手。

仓库 npm

三档难度共用一份编配，只换调号

出谱

需要本机先跑起出谱服务，页面才知道往哪送

五线谱与简谱

分页 PNG 与 SVG，指法标在符头上方
同一份编配的简谱文本，括号区分左右手
MusicXML 与 MIDI，导入 MuseScore 继续编辑

怎么跑

在 DSH 里

装上 pianochart-dsh，对话里让它出谱

本地出谱服务

python -m pianochart.serve，粘链接出谱

命令行

python -m pianochart.cli，一次出全套文件

本站不代跑

本站是静态页，转写在你本机跑

只做伴奏

人声被丢弃，纯人声段落出不了谱
