01

Envoy

把链接分享给你的 AI

给 Agent 一条链接，拿回来的不是「大概读过了」，而是带时间戳与来源坐标、能逐条引用的材料。网页、公众号、PDF、图片帖、B 站与本地视频都在本地取回处理。

  • 每段材料附 [mm:ss] 或页面/段落坐标，外加 material id
  • envoy_search 按关键词定位，envoy_expand 按需续读，不必一次吞下整篇
  • 没字幕、要登录、缺模态 → 统一标「待补」，不让模型用常识填坑

可用。 当前 v0.1.56、Apache-2.0，Claude Code / Codex / DeepSeek Harness 各一行命令安装。仓库里的 A/B 数据附带实验偏差说明，不代表「答案更准」——详见下方边界说明。

curl -fsSL https://raw.githubusercontent.com/regrevia/Envoy/main/integrations/install.sh | sh -s -- auto
envoy doctor --json

02

Revia

Agent 写程序，人治理语义图

一种面向 AI 原生开发的 graph-first 可执行语言：程序由 Agent 生成，人核验的是一张可确定序列化、能力 / 效果 / 错误 / 资源都显式的语义图。

  • checked semantic graph，而非自由文本式代码生成
  • deterministic serialization，同一张图得到同一份产物
  • capabilities / effects / errors / resources 全部显式声明，便于人工审查

研究预览。 open-source research / preview implementation，不是 Stable V1.0，也不是生产可用。适合读设计、读实现、讨论语言形态，不适合拿去上线。MPL-2.0。

03

Multiverse

Agent 编写的可移植工作流运行时

工作流包定义业务契约，环境绑定决定「怎么跑、在哪跑」。文件、schema、能力发现与可机器读的诊断构成 Agent 的编写界面，图形界面用于检查、审阅与人工任务。

  • capabilities / validate / preflight 返回带来源定位、值已脱敏的诊断
  • 本地 SQLite 运行时支持确定性 preset、人工审批节点与 durable child scope
  • 标准 HTTP Job 绑定以可信本地执行宿主为参考实现，提交与观测分离

本地开发预览。 可移植宿主嵌入、远程 Connector、飞书渠道与 Codex / Pi / Claude 会话管理目前都是 design targets, not completed integrations。生产托管、IAM、多 Worker 等尚未支持。

uv run mverse capabilities --json
uv run mverse preflight presets/content-delivery \
  --binding examples/bindings/content-local.yaml --json

快速开始

Envoy only

一行安装，三个宿主

安装脚本自带 uv 与 Python 3.11，装完跑一次自检即可。

curl -fsSL https://raw.githubusercontent.com/regrevia/Envoy/main/integrations/install.sh | sh -s -- claude-code
curl -fsSL https://raw.githubusercontent.com/regrevia/Envoy/main/integrations/install.sh | sh -s -- codex
curl -fsSL https://raw.githubusercontent.com/regrevia/Envoy/main/integrations/install.sh | sh -s -- dsh

envoy doctor --json

把参数换成 auto 可自动识别宿主；--profile minimal 只装 178 MB runtime，跳过约 683 MB 的 Chromium。

还有一组 DSH 插件

DeepSeek Harness 生态的小工具，已收录在社区插件榜单。

  • dsh-unlag不重启会话刷新插件状态
  • dsh-fast-mode按步骤自适应思考档位与批量并行工具调用
  • dsh-mobile-use移动端设备操作能力
  • envoy-dshEnvoy 的 DSH 接入包

边界与事实说明

  • Envoy 不绕过登录、验证码、地区限制与 DRM，也不替代联网搜索；PyPI 尚未发布，以 GitHub Release 为准。
  • 关于那组 A/B 数据（正常结束且未自报读不到 22%→92%、超时 68%→0%、命中参考事实关键词 23%→82%）：两臂时间上限不同（900s vs 2400s），完成率差距会被放大；verified 两臂均为 0，本轮没有人工判定答案对错；suspect_complete 只表示「正常结束且没自报读不到」，不等于答对。完整协议与偏差说明在仓库 benchmarks/fixed-set-v1。
  • 链接覆盖实验：100 条可达链接中 80 条可用、可达链接 92.5% 读出正文；未拿到的 24 条里 16 条是境外站点被本机代理出口挡住、8 条是登录墙或人机校验。
  • Revia 与 Multiverse 均为预览实现，页面上的功能描述以各自 README 的当前状态为准，未完成的集成已在上方逐条标明。
  • 本页不依赖任何第三方脚本、字体或统计服务；所有数字与版本号来自事实表复核，会随项目更新变化。
